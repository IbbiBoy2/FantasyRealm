# FantasyRealm Front End

Current step: homepage + public character gallery + character creator visual page.

This package is HTML/CSS only. No JavaScript, PHP, or database functionality has been added yet.

Important:
- `css/home.css` is the user's latest edited homepage CSS, including the latest desktop/mobile layout changes.
- `css/gallery.css` is the latest gallery CSS.
- `css/create-character.css` controls only the new character creator page.
- `pages/create-character.html` is the new creator/editor visual page.

Page-specific backgrounds are stored in `assets/backgrounds/`.
