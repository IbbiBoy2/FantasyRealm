# FantasyRealm Front-End

Static visual front-end only.

## Files
- `index.html` - page structure
- `css/style.css` - desktop styling
- `css/responsive.css` - tablet/phone styling
- `assets/` - ready for future images, logos and decorative files

Open `index.html` in your browser to view the page.

No JavaScript, PHP or database is included yet.
